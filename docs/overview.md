# 나의 페르소나, 보이스 메모아 (Me-Ari)

## 1. 프로젝트 개요
'목소리 일기'는 사용자의 Java Spring 숙련도를 활용하면서 최신 AI API를 연동하여 기술적 깊이를 더하는 웹 기반 애플리케이션입니다.

*   **핵심 가치**: "쓰지 말고 말하세요. AI가 당신의 하루를 한 편의 에세이와 한 장의 그림으로 남겨드립니다."

## 2. 주요 기능
1.  **감성 녹음**: 웹브라우저에서 직접 음성 녹음.
2.  **스마트 리라이팅**: STT(음성 인식) 후, 어색한 말투를 교정하여 세련된 일기 형식으로 재구성.
3.  **감정 분석 & 태깅**: 목소리의 톤과 내용을 분석해 '기쁨, 우울, 설렘' 등 감정 스탯 부여.
4.  **AI 일러스트**: 일기 내용을 바탕으로 그날의 분위기를 담은 AI 이미지 생성.
5.  **타임라인**: 캘린더 형태의 대시보드에서 과거의 나를 목소리와 글로 확인.
