# UI/UX 컨셉 (Web Responsive)

## 1. 전체 무드
'깊은 밤의 서재' 또는 '차분한 파스텔 톤'. 사용자가 진솔해질 수 있는 분위기를 지향합니다.

## 2. 주요 페이지 구성

### 2.1. Main Page
*   중앙에 커다란 **'마이크 아이콘'**과 파동 모양의 애니메이션.
*   하단 문구: "오늘 하루는 어땠나요?"

### 2.2. Recording View
*   녹음 중: 실시간 **음성 파형 (Visualizer)**이 움직이는 애니메이션 효과.
*   기능: '일시정지' 및 '완료' 버튼 제공.

### 2.3. Result View (Post-Processing)
*   **왼쪽**: AI가 다듬어준 텍스트 일기.
*   **오른쪽**: 일기 내용을 바탕으로 생성된 AI 이미지.
*   **하단**: 분석된 감정 리포트 (예: "오늘은 조금 지친 하루였네요. 70%의 피로도가 느껴져요.")
